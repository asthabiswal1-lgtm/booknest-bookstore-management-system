# BookNest - Bookstore Management System

A full-stack Bookstore Management System developed as an internship project.

## Project Overview

BookNest is a web application for managing books, customers, shopping carts, and orders. It provides separate functionality for customers and administrators.

## Features

- User registration and login
- Book browsing and search
- Genre filtering
- Book details
- Shopping cart
- Checkout and order creation
- Customer order history
- Admin dashboard
- Book management
- Order management
- User management
- Responsive design

## Technology Stack

### Frontend
- React
- React Router
- Context API

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt

## Project Status

Frontend UI and application screens have been developed. Backend API, database integration, authentication, testing, and deployment will be completed as part of the project development.
